MySQL的增删改查

上一篇以一个例子对MySQL语言开始大致熟悉，现展开详细地系统地学习
主要以AI给出的例子为基础进行对关键字及其用法的理解

增

INSERT INTO 表名(列名，列名，列名)
(xxx,xxx,xxx) —————— 基础格式为此，重要词汇 INSERT INTO
也可不指定列名，但增加时要按顺序提及所有列，自增则填NULL
也可插入其他表中数据

表示为将查询结果插入列表中
只插入部分列时（相对总表），其他列为空或默认值

查

基本语法
SELECT 列名 FROM 表名 WHERE 条件;

WHERE 条件查询：

<> — 也是不等于，同!=
—— 多个条件时 ——-
OR 和 AND 进行连接（两者意思不同）
AND表同时成立
IN判断字段的值是否等于列表中的任意一个值，相当于多个OR条件
一般写为 WHERE 列名 IN (值,值,值)
———– WHERE class IN ('一班', '二班', '三班')
LIKE ——- 模糊查询
示例 —- SELECT * FROM employees WHERE name LIKE '张%';
查询以 “xx” 开头的 LIKE 'xx%'
查询包含 “xx” 的 LIKE '%xx%'
查询以 “xx” 结尾的 LIKE '%xx'
其他查询示例演示
查询名字长度为 3 且第二个字是 “小” 的员工
SELECT * FROM employees WHERE name LIKE '_小_';
查询名字以 “李” 开头且至少有两个字的员工
SELECT * FROM employees WHERE name LIKE '李%' AND LENGTH(name) >= 2;
查询特殊符号时需要转义字符”",在转义字符后加需要查询的
—– 自定义转义字符 —–
使用 ‘/‘ 作为转义字符，查询包含 “%” 的字符串
SELECT * FROM products WHERE description LIKE '%/%%' ESCAPE '/';

排序、限制结果数量、去重

排序 - ORDER BY
限制结果数量 - LIMIT
去重 - DISTINCT
——— 排序 ———
— 升序排列
SELECT * FROM students ORDER BY age; — 升序是默认
SELECT * FROM students ORDER BY age ASC;
— 降序排列
SELECT * FROM students ORDER BY age DESC;
— 多列排序
SELECT * FROM students ORDER BY class, age DESC;
—–先按班级升序，再按年龄降序
——— 限制结果数量 ———
— 查询前3条
SELECT * FROM students LIMIT 3;
— 跳过前2条，查询3条
SELECT * FROM students LIMIT 2, 3;
SELECT * FROM students LIMIT 3 OFFSET 2; — 从第3条开始，查询3条
——— 去重 ———
— 查询所有不重复的班级
SELECT DISTINCT class FROM students;

聚合函数、分组查询

——— 聚合函数 ———
AVG() ———– AVG() 是聚合函数，计算该组的平均值
COUNT() ——— 计算行数或是非空的个数
SUM() ———– 计算数值列的总和
MAX() ———– 计算数值列的总和
MIN() ———– 返回最小值
SELECT 函数 FROM 数据库;
SELECT 函数 (AS 别名) FROM 数据库 (WHERE...);
——— 例 ———
SELECT COUNT(*) FROM students; —- 总记录数 *表总
SELECT COUNT(*) FROM students WHERE class = '一班';
SELECT AVG(age) AS 平均年龄 FROM students;
——— 分组查询 ———
GROUP BY 常与聚合函数连用 表示查询此列名下的数据
GROUP BY 可接列名，也可接关于列名的判断
——— 例 ———

只显示人数大于2的班级
HAVING在分组后对聚合结果进行过滤，通常与聚合函数一起使用
——— 多表查询 ———
多表联查中的不同连接
内连接 INNER JOIN - 只返回匹配的数据
左连接 LEFT JOIN - 返回左表所有数据，右表没匹配的显示NULL
右连接 RIGHT JOIN - 返回右表所有数据

改

——— 基本语法 ———
UPDATE 表名 SET 列1=值1, 列2=值2 WHERE 条件;
UPDATE 一定要加 WHERE 条件，否则会更新所有行！
——— 例 ———
UPDATE students SET age = 20 WHERE name = '张三';
— 将张三的年龄改为20
UPDATE students SET age = age + 1;

删

——— 基本语法 ———
DELETE FROM 表名 WHERE 条件;
DELETE 一定要加 WHERE 条件，否则会删除所有数据！
——— 例 ———
DELETE FROM students WHERE name = '张三';
— 删除名为张三的学生
DELETE FROM students;
— 删除表中所有数据，但保留表结构 新数据自增列会继续递增
TRUNCATE TABLE students;
— 更快的删除所有数据方式（重置自增ID即ID重新从1开始）
两者都不改变表的结构，键，约束，都又可以重新增加数据了

假如给我三天光明

假如给我三天光明

若要给一个盲人三天光明，理所应当地理解为给他三天可以看到东西的时间。给一个瞎子
三天光明，也可以是让他听见。对于有缺陷的主体来说，光明可以是完整，是无暇。总闻
言，人无完人。所以，光明听来可以赋予所有人。但真的是这样吗。

对于不同的缺陷个体来说，这三天的光明的感受也截然不同。曾经完好过的和生来便是缺
陷的。于史铁生来看，他十分地渴望自己的双腿变回正常的样子，在这段时间里他十分痛
苦，经过了好久归于平静。倘若这个时候让他完整三天，他会怎么想呢。是更加悲哀于现
状，还是欣然感受这三天的美好呢。不敢揣测。于一个天生盲人，三天的视野可能会让他
以后的想象更有原料，让他感受视野带来的方便，让他对世间美好的东西有种体验，他也
许因此觉得无憾。

假如给我三天光明，假如在这三天补偿我的缺陷。试想一下，有什么样的意义呢。首先，
并无影响生活的缺陷等待补偿，倘若有的话，这三天让我变成我心中完美的样子吗。听起
来似乎不错，可是，这只是三天的光明，过完这三天，变回原样，我还是原本的我。三天
里，我可以使用这具身体做些什么呢，无非还是正常的生活。所以，物理意义上，对于我
的身体来说，这三天的光明是没有任何意义的。最大的影响似乎出在心理上。由于这一种
条件，是我从未拥有过的，所以，大概和我想的天生盲人的想法差不多。

假如给我三天光明，假如三天真正的光明。我们的生活是黑暗的，这样的黑暗是看不见的
黑暗，这样的黑暗是遮天蔽日的。压力就像是一个会长大的书包，随着时间渐渐变大，渐
渐长到头顶，遮住我们的光明。小学的时候，少量的作业和背诵是我们的压力。初中的时
候，作业直观地变多了，可能比小学多了更多的补习班，我们还需要考上一个不错的高
中。高中的时候，我们为了补习班到处奔波，因为学习把自己心理压垮。大学的时候，我
们开始想未来，以往看来很远地未来就在眼前了，我们要以一种什么样的姿态去迎接它呢
我们或许疑惑或许迷茫，或许清醒地去拼搏。书包长大了，书包变重了，书包遮住我们的
光源了。你更累了。假如这个时候有人要给我三天光明，将我的书包摘掉，让我看到那明
亮的光源。你会拒绝，因为你知道，过几天书包又会回到你身上了。这三天光明没有意
义。

一些MySQL浅层知识

启动MySQL

powershell能力强大，它可进行很多指令。
powershell中的一些语言词句也已经忘记，等后来想起再做记录。

想要使用mysql，需要启mysql服务器。
启动服务器需要的操作：net start mysql80
还可能是其他版本，就将mysql80改成别的。
一般时候我们可以将MySQL部署在环境变量中，这样就不用每次开机都启动服务器了
想要使用MySQL，就要启动mysql客户端。
在powershell中输入：“mysql -u root -p”然后出现：“Enter password:”
随后输入下载时设置好的密码，就打开成功了。
其中，-u root 是指 指定登录用户名为 root。这个是在下载时默认的。
-p 表示需要密码
这个时候powershell中输入行前就会变为 mysql>
就表示成功进入了MySQL服务器，可以输入指令使用mysql了

MySQL中一些语法以及语言

两个重要概念

1.在使用MySQL即和MySQL对话的时候，在语句末尾需要加上分号“;”才可以回车运行。

2.MySQL关键字不区分大小写，也就是一个词语可以大小写混杂地写，但是没有必要。
不过在书写时，一般习惯将命令、关键字等写为大写的形式。
如CREATE和cReATe是完全一样的两条命令。

不过变量的名称是严格区分大小写的，大小写不同表示的不同的事务。
prose和Prose是两个不同的东西

一些基础语句

其中很多都是十分片面的，只是记录了要实现这个共功能所需的，
其他的需要更多学习研究，当下学习内容服务于熟悉操作

接下来语句均是在powershell中书写

CREATE DATABASE +name——–表示创建一个名字为name的数据库
USE name———————表示使用这个数据库
SHOW DATABASES—————表示列举出所有数据库
创建并打开数据库后就需要对其进行操作,此时数据库里空空的，什么都没有。
我们先来创建列表（下面列表中明细不空，作为示例，先以学生名表为示例学习）

CREATE TABLE语句的基本结构
CREATE TABLE 表名 (
列名1 数据类型 [约束],
列名2 数据类型 [约束],
…
[表级约束]
)；
一些表级约束
PRIMARY KEY()————-表示复合主键 各键不为空
其中各个键用逗号隔开，表示此组合只能出现一次，但其中各个键是可以出现重复的
FORMARY KEY()————-表示外键，与其他表格关联 可以出现多个 可为空
书写格式
[CONSTRAINT 约束名] UNIQUE (列名1, 列名2, …)
CONSTRAINT 约束名 是可选的，如果省略，MySQL 会自动生成一个名字。
括号内列出组成唯一约束的列名，用逗号分隔。
一些列级约束
NOT NULL——————–确保该列不能有 NULL 值，即不为空
DEFAULT———————为列指定默认值。插入数据时若未给该列赋值，则使用默认值。
如：age INT DEFAULT 18
UNIQUE———————–保证该列的所有值都不重复。可以有多个 NULL 值
PRIMARY KEY——————单列设为主键 隐含了 NOT NULL 和 UNIQUE
AUTO_INCREMENT—————不是约束，而是属性，但经常与主键一起使用
id、name、subject等是列名，简单理解为表格中的列
INT——————表示数据类型是整数
PRIMARY KEY———-说明这个键是主键
———————主键的特点：
———————值必须唯一（不能重复）
———————不能为空（NOT NULL）
———————一个表只能有一个主键（但可以由多个列联合组成复合主键）
AUTO_INCREMENT——-自动递增属性。当插入新记录时，如果没有给该列指定值，
———————MySQL 会自动生成一个比当前最大值大 1 的整数。
———————所以若不给出定义，这个id就会从1但顺序低等
VARCHAR(n)———–可变长度字符串类型。n表示最大字符数为n

向列表中插入数据
INSERT INTO student_scores (name, subject, score) VALUES

(xxx,xxx,xxx),

(xxx,xxx,xxx);——–此处注意格式，括号中数据用逗号分隔，语句最后加分号
INSERT INTO 表名 (列1，列2，…) VALUES (值1，值2，…); 基本格式

查询表中的数据
SELECT * FROM student_scores;
SELECT * —————- 查询命令 * 表示“所有列”
FROM name—————–指定要从哪个表查询
SELECT * FROM student_scores WHERE name = ‘张三’;
WHERE———————后加过滤条件，可选择固定人，或者比较大小
SELECT name, AVG(score) AS 平均分
FROM student_scores
GROUP BY name;
SELECT name————-选择需要显示的列名
AVG()——————-AVG() 是聚合函数，计算该组的平均值
COUNT()—————–计算行数或是非空的个数
SUM()——————-计算数值列的总和
MAX()——————-计算数值列的总和
MIN()——————-返回最小值
AS———————-后可接中文，相当于给AVG()起名
GROUP BY name———–将数据按 name 列分组，然后对每一组应用聚合函数

两表关联
先看下面代码时示例

FOREING KEY————–外键，联系两表
(student_id)————-指定哪一键是外键
REFERENCES students(student_id)—-指定引用哪个表的哪一列。
———————————–这里表示 scores 表的 student_id 必须
———————————–与 students 表的 student_id 列中的值相匹配。
FOREIGN KEY … REFERENCES …—–外键表示连接
———————————–在键入成绩表时，需要注意提到上面的外键
两表关联的查询
最基础格式

SELECT—————表示要选择的列
xxx.xxx————–列的表达格式“表名.列名”
AS XX—————-给列重起一个名字
FROM xxx————-表明指定主表
INNER JOIN xxx——-内连接 xxx 表
ON students.student_id = scores.student_id
———————连接条件，即两个外键
WHERE—————-筛选保留名字是张三的记录
AND——————表同时满足WHERE的多个条件

GROUP BY—————按哪些列进行分组
HAVING—————–表示对分组后结果进行过滤
———————–与WHERE不同，WHERE是在分组前执行的
